15:Tec8,<p>该指南来自于一次自我感觉<a href="/alpacanotes/articles/git-incident-2025-09-28">惊险的经历</a>，</p>
<blockquote>
<p>一份精简但可操作的“掉历史”自救清单：当你在 GUI 或命令行误操作后，发现最近提交“消失”时，如何快速定位并安全恢复。</p>
</blockquote>
<h2 id="典型症状">典型症状</h2>
<ul>
<li><strong>近期提交不见了</strong>：<code>git log</code> 顶端不是你刚做的提交。</li>
<li><strong>工作区回到旧版本</strong>：本地文件和远端网站内容明显“时光倒流”。</li>
<li><strong>远端与本地不一致</strong>：<code>git status -sb</code> 显示 <code>main...origin/main [ahead N|behind N]</code>。</li>
</ul>
<h2 id="成因与诱因简明">成因与诱因（简明）</h2>
<ul>
<li><strong>直接成因</strong>：分支指针被移到旧提交，或进入分离 HEAD，导致近期提交不在当前分支历史中。</li>
<li><strong>前几天可能埋下的雷</strong>：
<ul>
<li>直接 <code>git checkout &#x3C;commit></code> 查看旧版本后继续开发/提交；</li>
<li>用 GUI 的“Checkout/Reset/Restore”类功能回到旧提交但未建保护分支；</li>
<li>偶发 <code>git reset --hard &#x3C;old></code>；</li>
<li>未及时推送，远端与本地脱节，引发误判。</li>
</ul>
</li>
<li><strong>今天触发的动作</strong>：在 GUI 中对某个旧提交执行了“Checkout/Reset”，把当前分支（例如 <code>main</code>）指针回退了。</li>
</ul>
<h2 id="本次拯救摘要">本次拯救（摘要）</h2>
<ol>
<li>
<p>用 <code>reflog</code> 找到目标提交 <code>&#x3C;sha></code>（历史未丢，只是指针偏了）。</p>
</li>
<li>
<p>二选一恢复：</p>
</li>
</ol>
<pre><code class="language-bash"># 安全合并法（推荐）
git checkout -b restore-work &#x3C;sha>
git checkout main
git merge restore-work

# 或：直接重置法（快捷）
git checkout main
git reset --hard &#x3C;sha>
</code></pre>
<ol start="3">
<li>如远端历史需以本地为准：<code>git push -f origin main</code></li>
</ol>
<h2 id="恢复步骤">恢复步骤</h2>
<pre><code class="language-bash"># 1) 快速浏览当前可达历史
git log --oneline -10

# 2) 关键：查看 HEAD 的移动“航迹记录”
git reflog -20
</code></pre>
<ul>
<li>在 <code>reflog</code> 输出中，<strong>找到你需要回到的那次正确提交的 SHA</strong>（记为 <code>&#x3C;sha></code>）。</li>
</ul>
<h2 id="两种恢复方式择一">两种恢复方式（择一）</h2>
<pre><code class="language-bash"># 从目标提交创建保护分支
git checkout -b restore-work &#x3C;sha>

# 回到主分支并合并恢复
git checkout main
git merge restore-work
</code></pre>
<p>说明：保留现场，历史连贯，最不容易出岔子。</p>
<pre><code class="language-bash">git checkout main
git reset --hard &#x3C;sha>
</code></pre>
<p>说明：让当前分支指针“瞬移”到 <code>&#x3C;sha></code>；如远端不是你想要的历史，后续可能需要强推。</p>
<h2 id="同步远端如有需要">同步远端（如有需要）</h2>
<pre><code class="language-bash"># 仅当你确认“本地才是正确历史”时才执行强推！
git push -f origin main
</code></pre>
<h2 id="预防与习惯精简版">预防与习惯（精简版）</h2>
<ul>
<li><strong>查看旧版本用新分支</strong>：<code>git checkout -b inspect-&#x3C;date> &#x3C;sha></code>。</li>
<li><strong>小步提交，及时推送</strong>：远端即备份。</li>
<li><strong>危险操作前打快照</strong>：<code>git branch backup-&#x3C;date></code> 或 <code>git tag safety-&#x3C;date></code>。</li>
<li><strong>丢历史先看 reflog</strong>：优先 <code>git reflog</code>，再考虑其他。</li>
