PART III · ADVANCED & ECOSYSTEM

三、高阶管理与生态篇 (27-38)

27 · Vault Payments [21:20]

保险库支付

在设置中安全存储信用卡与登录凭证（附带使用场景提示 Hint），Bot 可在结账时像 Apple Pay 一样自动填充支付而无法直接窥见卡号明文。

28 · Buying Within Chat [21:54]

聊天窗内直接购物与物流追踪

在对话中直接展示带图片、评分和价格的商品卡片，点击“Buy Now”即可下单并由 Bot 全程追踪发货与物流状态。

29 · 1Password Integration [22:13]

1Password 原生集成

通过应用连接器直接绑定 1Password 密码库，在不向 Agent 暴露密码明文的前提下完成各类网站授权登录。

30 · Making Phone Calls [22:34]

代打电话

支持让 Bot 直接拨打真实电话去跟进订单或咨询商户信息（目前仅限美国地区开放）。

31 · Alignment (/align & /grillme) [23:08]

任务前对齐机制

在执行大型端到端项目前，强制让 Bot 先列出编号问题清单及选项建议，对齐需求细节后再动工，避免跑偏浪费额度。

32 · Using Your Own Computer [23:50]

挂载本地电脑与导入 Claude 技能

授权 Grok Bot 直接读取本地电脑上的表格、图片等文件，甚至直接扫描并导入本地已有的 Claude Code 技能库。

33 · Claude Code or Codex Bridge [24:35]

Claude Code / Codex 桥接

通过 Webhook 例程将 Claude Code 与 Grok Bot 打通，实现双向派活、同步业务记忆，或让 Claude Code 借用 Grok Bot 免费检索 X 数据的能力。

34 · Central Computer Setup [25:05]

中央主机架构

利用一台 24 小时常开的设备（如 Mac mini、迷你主机或 VPS）集中存放所有文件、技能与业务上下文，让 Claude Code 和 Grok Bot 同时挂载连接。

35 · Keeping a Backlog [25:55]

待办任务池与看板

连接 Linear、Todoist，或直接用 Grok Bot Page 搭建包含“待办 / 进行中 / 已完成”的看板（Kanban），弥补纯聊天界面不适合管理长线任务的短板。

36-38 · Report Card, Templates & Marketplace

Bot 绩效成绩单与模板市场

36 · BOT REPORT CARD [26:37]

绩效评估：指定一个 HR Bot（如 Dr. Eggbot）每周对所有子 Bot 按 10 分制打分，揪出表现下滑或乱耗额度的 Agent 并给出修复建议。

37 · SHARING BOTS AS TEMPLATES [27:09]

导出分享模板：一键生成分享链接，仅导出 Bot 的名称、描述、技能和例程（自动剥离个人电脑文件与隐私凭证）。

38 · BOT MARKETPLACE [27:34]

官方 Bot 市场：访问 xAI 官方市场获取社区与官方团队构建的各行业 Bot 模板，或把市场链接发给主 Bot 让其挑选适合你业务的模板。

PART I · 01 — 13

一、入门基础篇（Foundation & Core Setup）

14 SUB-ITEMS EXPLAINED [00:43 - 10:08]
01 · Importing Memory [00:43]

导入记忆与上下文

支持从 ChatGPT 或 Claude 直接导入历史记忆，或让 Grok Bot 通过逐个提问的访谈方式快速建立业务背景。

02 · Hiring Other Bots [01:37]

让主 Bot 招募子 Bot

主 Bot 天生具备编排器（Orchestrator）属性，可根据业务需求自动创建并配置具有独立职责的子 Agent（遵循“精简团队”原则）。

03 · Official Bot Designer [02:47]

Dr. Eggbot（官方 Bot 设计器）

由 xAI 首席工程师 Lauren Tan 分享的模板，专门用于按最佳实践设计新 Bot，为其设定单一明确的目标及“禁止事项清单（Anti-jobs）”。

04 · Naming Your Bots Well [03:38]

高效命名规范

采用简短且能一眼看出职能的命名方式（如主控叫 Groko、安全叫 Seco、差旅叫 Travo），方便在侧边栏查找及在对话或语音中直接提及调用。

05 · Automating Your Inbox [04:46]

收件箱自动化与每日摘要

通过连接器（Connectors）绑定多个 Gmail 账号，每日自动生成单行邮件摘要，并用图标标记置顶高亮重要邮件。

06 · Cards for Review [06:06]

待审卡片机制

Bot 起草的邮件或 Slack 消息默认以卡片形式等待人工审核，支持修改确认后再点击发送，防止自动外发失误。

07 · Talking Instead of Typing [06:30]

语音输入与意图复述

支持麦克风语音输入（桌面端快捷键 Ctrl/Cmd + D）快速倾倒任务，并可要求 Bot 先复述理解的意图以防偏差。

08A · Voice Memo Replies [07:12]

语音备忘录回复

Bot 可发送语音条进行回复，支持展开文字转录稿，且点击转录稿中的任意单词即可跳转到对应的音频位置。

08B · Voice Mode (Bonus) [07:38]

实时语音通话模式

点击右下角波形图标即可像打电话一样与 Agent 进行实时的双向语音对话。

09 · Skills (/digest) [07:53]

技能指令封装

将重复使用的提示词保存为斜杠指令（如 /digest），也可让 Bot 根据历史聊天记录自动推荐值得封装为 Skill 的高频操作。

10 · Finding Your Usage Hog [08:24]

排查额度消耗大户

Agent 具备查看账户额度消耗的权限，可直接询问哪个 Bot 本周消耗最多 Token 并让其给出缩减建议。

11 · Pages (Visual Artifacts) [09:03]

可视化页面（Pages）

类似 Claude Artifacts，支持将报告、追踪表、清单或仪表盘生成独立的可视化页面，支持生成链接分享以及按计划定期更新。

12 · Sections & Pins [09:49]

分组与置顶

右键点击侧边栏的 Bot，可按“商业”、“个人”等自定义分组（Sections）进行归类，或将高频 Bot 置顶（Pin）。

13 · Custom Icons & Openbot Avatar [10:08]

自定义图标与动画

支持修改 Bot 的图标形状与颜色（甚至用自然语言指令让主 Bot 批量按分组改色），或接入开源项目 Openbot Avatar 生成专属动画图标。

PART II · 14 — 26

二、进阶自动化篇（Automation, Routines & Multi-Agent）

14 SUB-ITEMS EXPLAINED [11:41 - 20:29]
14 · Phone Apps Integration [11:41]

调用手机端原生应用

在 iOS 和 Android 端授权后，可直接操作手机日历、通讯录、定位、闹钟（iPhone 端还额外支持提醒事项与 Apple Home）。

15 · Action Button Shortcut [12:17]

iPhone 操作按钮一键呼出

将 iPhone 的 Action Button 绑定为“开始 Grok Bot 语音聊天”，随时随地一键派发任务。

16 · Chief of Staff (/inbox) [12:47]

幕僚长模式

利用主 Bot 跨会话巡检所有子 Bot 的状态（例如输入 /inbox），汇总列出所有正在等待你做决定的事项。

17 · Cloud Routines [13:27]

云端定时例程（Routines）

设定按计划自动执行的定时任务；所有例程均在云端运行，即使关闭电脑或手机也会照常执行。

18 · Passive / Quiet Routines [13:55]

静默例程

在后台定期运行巡检（如安全监控 Bot 每隔几小时扫描全网漏洞新闻），平时保持静默，仅在发现真正重要的异常时才发送通知打扰你。

19 · Creating Skills by Showing [14:59]

接管电脑演示教学

打开桌面端的“Computer View（电脑视图）”并点击“Take Control（接管控制）”，亲自在网页上操作一遍流程，让 Bot 观察学习并保存为技能。

20 · Deterministic Code [15:44]

将技能转化为确定性代码

让 Bot 审计现有的例程，将固定流程转化为无需调用大模型的传统脚本代码，从而大幅节省 Token 额度。

21A · Bot Handoffs [16:18]

跨 Bot 任务交接

由于各 Bot 默认拥有独立的记忆文件夹，可通过自然语言指令让一个 Bot 直接向另一个 Bot 发消息索取数据或交接工作。

21B · Bot Group Chats [17:03]

多 Bot 群聊协作

使用快捷键 Cmd/Ctrl + Shift + N 将多个专业 Bot 拉入同一个群聊线程中，针对单一项目协同讨论并共享上下文。

22 · Shared Brains [17:36]

共享大脑文件夹

在云端电脑中建立所有 Bot 均可读取的公共目录，用于存放全局规则、品牌规范或前端设计系统（Design System）。

23 · Event Triggers & Webhooks [18:16]

事件触发器

无需等待定时计划，当收到特定邮件、Slack 消息、GitHub 动态或外部网站表单的 Webhook 推送时，立即唤醒 Bot 执行任务。

24 · Agent's Own Inbox [19:05]

申请专属收件箱

每个账号可在 mail.grokbot.com 域名下为自己的 Agent 免费申领一个专属邮箱地址，可用于自动注册网站账号或订阅简报。

25 · Routine Scout [19:51]

例程侦察兵

设置每周定期扫描你的人工提问历史，自动识别重复性劳动并推荐可将其自动化的新 Routine 方案。

26 · Scanning X for Tips [20:29]

自动检索 X 平台最新技巧

依托与 X（原 Twitter）同属一家公司的原生优势，让 Bot 自动在 X 上搜索最新的 Grok Bot 玩法并融入自动化建议中。
