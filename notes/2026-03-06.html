    昨天晚上折腾了一件非常失败的事情。

    我当时更新了一些网站内容，本来以为提交之后就会自动触发部署，结果发现网页一直没有更新。于是开始排查问题，一步一步往下查，越查越困惑。表面上看所有配置都没有问题，但部署就是没有触发，更新内容始终没有同步到网站上。

    这个过程让我一度开始怀疑自己，是不是哪里配置写错了，或者改动的时候漏掉了什么关键步骤。前前后后折腾了差不多一个小时。

    后来我开始换个方向检查，去 GitHub 上看了一下 Actions 的额度，怀疑是不是额度用完导致任务无法运行。结果发现余额完全充足，不存在这个问题。

    于是我去推特上搜了一下 GitHub Actions，这才发现很多人都在发同样的情况——服务宕机了。到这一步才意识到，前面那一大堆排查其实都和我没什么关系。

    这种事情确实很让人沮丧。结果当然是好的——问题不是自己造成的。但时间实实在在浪费掉了。

    后来想想，如果系统本身出了问题，这时候还在那里反复做自我反思，甚至怀疑自己的配置，那基本就是在做一件很愚蠢的事情。很多时候问题根本不在自己身上。
