<p>经济依赖：美国独立后仍是个农业国，高度依赖英国市场和投资，处于世界经济的边缘地位。</p>

<p>政治军事冲突：英国以边界纠纷为借口长期驻军俄亥俄，策动印第安部族抗美；1812年战争中英军攻入华盛顿，火烧白宫等。</p>

<h3 id="13">13.</h3>
<p>20世纪初，美国对法国电影的影响非常敏感。</p>
<p>当时法国电影在美国市场占据主导地位，引发了美国人对外来文化的焦虑，认为法国电影过于"阴柔"，会侵蚀"在西部拓荒运动中形成的伟大美国精神"。1909年，美国成立了国家审查协会，对电影实施审查，法国电影被拒审、要求删减或修改的频率明显高于美国本土电影</p>

<h3 id="14">14.</h3>
<p>这种敏感在文化领域表现得尤为明显，如阿斯特剧场骚乱（1849年）就是因为英国演员麦克雷迪在纽约演出，引发了美国人对"英国戏子"的强烈反感，最终导致骚乱。</p>
<p>美国的这种"破防"心态与其作为后殖民国家的身份密切相关，直到美国实力超越英国，成为新帝国，英美矛盾才逐渐化解。</p>

<h3 id="16">16.</h3>
<p>有没有一种可能：我们从来都不曾主宰过自己的命运。</p>
<p>我们几十年人生都只是大自然的馈赠。我们只是在一个狭小的生存空间为自身的诡异行为赋予意义，从而以自我感动地形式来对抗虚无？</p>
<p>AI来了，我们不过是从一种狭小空间换成了另一种狭小空间。那些尊严感会被消解掉，然后我们重构出一种新的尊严感。</p>

<h3 id="17">17.</h3>
<p>有些工作会被淘汰掉，有些人会被取代掉。</p>
<p>任何工作都有能挣大钱的时候，也有成为夕阳工作并逐渐被淘汰掉的时候。</p>
<p>演变背后依托的是供求关系。技术的确起到了作用，但技术的变革也是为了克服供不应求的困境。变革之后，供求关系也变化了，之前稀缺的技能变得不再稀缺，之前很容易搞钱的活搞不到钱了</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289485805678916">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="18">18.</h3>
<p>人类擅长什么？到目前位置，几乎所有人类擅长的活动都可以通过工具做得更好。在自己创造的工具面前，人类在对应的能力方面几乎没有任何优势。</p>
<p>技术是人类能力的杠杆，让人类可以更壮、更快、更能重复。AI在这方面并没有与之前的技术变革有本质区别。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289483708551503">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="19">19.</h3>
<p>编程高贵吗？当然，编程需要技术门槛。</p>
<p>但是钳工、砌墙、种地也有技术门槛。只是这些工作所依托的核心能力有所差异，有的体现在知识上，有的体现在动手能力上、耐力上体、力量上。</p>
<p>编程并不比这些更更加高贵。计算机刚发明的时候，编程是男性工程师不屑于去做的低级工作，让编程高贵的是市场需求</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289490813730918">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="20">20.</h3>
<p>编程的需求是怎么来的？这个需求来自于我们需要不厌其烦地去做一些重复工作。</p>
<p>对这些工作的精确描述以及对单次执行效率的优化是没有之境的，在这个过程中，需要重复的新工作就会被不断地发现。</p>
<p>这也就导致了任务的复杂性不断增加，也就有了软件工程的发展以及编程岗位的增加。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289494147826138">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="21">21.</h3>
<p>有了AI之后，人类需要处理任务的复杂度会降低还是会增加呢？这恐怕不是一个问题。</p>
<p>AI会把它能做的事情给做了，然后制造更多的问题需要人类去定义去优化。</p>
<p>当然，可能AI会把它制造的问题也都给解决掉，完成一种闭环，这样就彻底没有人类存在的必要了。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289496769270263">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="22">22.</h3>
<p>这背后关键的问题是，AI是工具还是物种？</p>
<p>工具是用完即可丢弃的，它不具备对环境的适应能力和演化能力。物种则需要充分利用环境的各种馈赠然后与环境“和谐共处”，从而让种群持续下去。</p>
<p>AI是人类创造的东西，显然它具备典型的工具属性。AI距离物种还有多远呢？人类有能力去创造新物种吗？</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289499135172657">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="23">23.</h3>
<p>我相信依靠人类的能力，是不可能创造新物种的。</p>
<p>人类会促进既有物种的演化，包括人类自己，但不具备从零创造物种的能力。人类对世界的感知能力是有限的，自然界有很多细节，甚至连观察的能力都不具备，何况将这些要素纳入物种设计流程？</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1959289504071819446">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="24">24.</h3>
