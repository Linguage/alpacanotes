13:T223c,<h3 id="1">1.</h3>
<p>在睡梦中“听”《盛世的崩塌》，具体内容没有多少印象，但帮我确认了一个看法：权力就是一个杠杆，位置越高，倍率越高。</p>
<p>有了权力，每一个小动作都会对社会产生巨大影响，有的是正面的，有的是负面的。比如《长安的荔枝》,一句话就可以让一群人遭殃，而这也只是冰山一角。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991912373383177">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="2">2.</h3>
<p>对一个帝王而言，对权力的掌控当然很重要，因为事关国家安定。因为总有一些人会“逢君之恶”,  别有用心地附和上头的各种决策，放大杠杆作用并从中牟利。</p>
<p>这些帝王更需要反馈机制，避免掌权之后的失控。比如唐太宗有魏征这样的“镜子”，至少能时刻意识到自己决策存在犯错误的可能性。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991914185314486">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="3">3.</h3>
<p>唐玄宗年轻时比较清醒，但年龄渐长，他对权力的掌控越发强势，而执政的目标也越发好大喜功，只想开疆拓土却忘记了其权力所依托的百姓的状况。</p>
<p>李林甫这种权臣，在他面前就是条狗。但李林甫又是一条渴望独宠的狗，用尽心机来排挤新鲜血液进入朝堂，彻底堵住了玄宗视听。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991917763064032">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="4">4.</h3>
<p>唐玄宗应该清楚李林甫的货色。但他在后期缺乏自我否定的魄力，可能是他知道自己屁股也不干净，“一日杀三子”的英勇事迹之后，他算是彻底摆烂了。毕竟对这些事情进行自我批评，恐怕他自裁都不过分。</p>
<p>下面已经没办法正常跟他交流了，因为他更需要的是逃避，是用各种纸醉金迷来掩埋那些不堪。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991921365971127">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="5">5.</h3>
<p>这一切的悲剧似乎都源自于权力的杠杆效应，但这个杠杆却没有负反馈机制。</p>
<p>操纵杠杆的人注定会对它的失误制造的麻烦变得麻木，一个人从良心上无法承受这些后果。</p>
<p>而没有了良知和情感，仅仅是一些抽象且可被随意伪造的数字，又如何形成反馈呢？</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991925073736211">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="6">6.</h3>
<p>当他们午夜梦回，意识到罪孽深重，非一人可承担之时，他们能做的就是彻底忽略这些事实，自我蒙蔽自我陶醉。</p>
<p>这种状态下，他们没有能力对自己的行为负责。而如果他们就是权力的最终责任人，那只有这个权力体系的崩溃才足以告慰天下。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1957991930035597412">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="7">7.</h3>
<p>我一直认为，科研的从业者有义务去用老百姓听得懂的语言来诠释他们的工作。</p>
<p>一方面是因为他们自己不直接产生经济效益，而是完全吃纳税人的钱，另一方面，这种努力可以帮助扩大他们工作的影响力。</p>
<p>只有老百姓认识到这些工作的价值，这些工作才会富有长久的生命力。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1958044267399770413">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="8">8.</h3>
<p>陶哲轩一直是我特别喜欢的公众人物。我不能说他在数学方面对我产生过影响，但是他的科普确实给我带来过很多启发。</p>
<p>以我在中国从事科研时所了解到的事情来看，有些经费被削减是大快人心的，有太多的经费滥用与腐败。</p>
<p>但从产出来说，在科研上的投入应该还是正面的，至少比其他方面财政投入的性价比高。</p>
<p><strong>原帖链接：</strong> <a href="https://x.com/AztecaAlpaca/status/1958044265122246760">阿兹特克小羊驼🦙 (@AztecaAlpaca)</a></p>
<h3 id="9">9.</h3>
<p>但显然，这种工作是费力不讨好的，因为科研单位已经非常官僚化了，只有向上管理才能带来收益：刷论文、写本子、参加各种会议，几乎所有的精力都用在了讨好更强势的那个群体。</p>
<p>我们不能指望连教学任务都不愿意承担的人去向公众进行科普。</p>
